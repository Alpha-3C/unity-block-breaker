# Block Breaker 素材说明

本工程在 `Assets/Block Breaker/` 中使用四张 PNG：

| 文件 | 场景用途 |
| --- | --- |
| `ball.png` | 小球 |
| `bg.png` | 背景与边界 |
| `brick.png` | 砖块 |
| `player.png` | 玩家挡板 |

截至 2026-10-20，工程内没有发现这四张图片的原始下载地址、作者或许可文件，因此这里不推测其授权方式。以后确认来源时，应补充原链接、作者、许可及是否修改；如无法确认公开使用权限，可替换为自行制作或许可明确的图片。Unity 的 `.meta` 文件随图片一同保留，以维持场景与 Prefab 的资源引用。
